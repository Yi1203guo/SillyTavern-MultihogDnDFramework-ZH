                                地图构架师 (Map Architect)
                                

                            

                            

                                

                                    

                                        当叙述者首次进入未绘制地图的地点时，地图构架师首先生成并锁定其房间/区域拓扑，然后针对这些确切的区域 ID 运行独立的内容放置阶段。在两个阶段均验证通过前不会存储任何内容。

                    世界推演 (World Progression)
                    

                

                

                    

                        

                            世界推演会在固定的游戏内时间间隔自动生成幕后世界模拟报告。
                            报告由独立的 LLM 阶段编写，并保存在 {prefix}_World 世界书中。
                            触发机制是确定性的 — JavaScript 在每次状态追踪器更新后检查 [TIME] 块；
                            AI 仅负责撰写报告，绝不自行决定是否生成报告。
                        


                        
                        

                            

                                
                                快速入门指南
                                

                            

                            

                                
创建世界骨架 (World Skeleton) 是可选的，但建议创建。它会在玩家所处的即时环境之外，播种更多地点以及更广阔的世界前提设定。世界推演随后会读取每个选中地点的完整设定档案，但绝不会接收其隐藏地图。

                                
    
                                    
  1. 创建骨架源：可以填写简短的主题种子，也可以填写详尽的世界描述。自动生成可以安全地从近期聊天中提取通用的世界背景，而不会将具体具名故事实体带入骨架中。您也可以在下方引用现有的世界书。
    2. 
                                    
  2. 生成骨架：点击生成骨架。地点将成为潜在的宏观模拟对象；阵营与冲突将提供大世界背景。具名实体可能会补充地点档案，但绝不会被世界推演独立推进。
    3. 
                                    
  3. 设置地点轮转：选择单篇报告涵盖多少个地点。最久未推进的地点将被优先选中，并可选择仅在同样未推进的候选中进行随机排序。
    4. 
                                    
  4. 生成第一篇报告：使用立即生成立即触发报告，或让其自动触发。其叙述性正文会立即对叙述者产生引导倾向；相关地图随后会在其常规地图演进阶段运行时体现这些变化。
    5. 
                                

                                

                                    
杂项说明

                                    
    
                                        
  • 世界推演可能会将地点档案中具名的人物、建筑和次级地点作为约束条件读取，但不会推演这些细粒度实体。
    • 
                                        
  • 24小时对于世界报告的自动生成似乎是一个不错的时间间隔，但鼓励您尝试更短（或更长）的间隔。
    • 
                                        
  • 您随时都可以按自己的意愿手动触发世界推演。
    • 
                                        
  • 注入位置会影响世界报告的显眼程度（可在下方的上下文注入设置中调整）。报告位置越低（越接近最新消息），叙述者就越容易注意到该报告。

                    冒险同伴 (Adventure Companion)
                    

                

                

                    

                        
通过状态追踪器顶部的 CHAT（聊天）按钮打开冒险同伴。在启用教程模式 (TUTORIAL MODE) 时，它可以为您的冒险提供帮助，助您快速掌握本扩展。在此模式下，它能够访问完整的文档。

此外，当您想就冒险进行闲聊或头脑风暴时，它也会伴您左右。您还可以让它在状态追踪器、世界书代理或地图更新器中进行修改，如果您要求，它还能为您执行操作（例如代您输入消息或做出 CYOA 模式的选择）。
